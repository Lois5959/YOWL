# Gym Connect — frontend

React 19 + TypeScript + Vite + Tailwind CSS.

```bash
npm ci
npm run dev      # http://localhost:5173 (le proxy Vite relaie /api vers http://localhost:3000)
npm run lint
npm run build    # fichiers statiques dans dist/, servis par Nginx en production
```

Voir le [README principal](../README.md) pour lancer toute l'application avec Docker.
