# Benchmark

| Solution | Limite principale | Différence de notre projet |
| :--- | :--- | :--- |
| **Tinder du Sport (Gymder)** | Trop lent, axé rencontre/drague. | **Instantanéité :** Besoin d'aide dans la minute. |
| **Groupes Facebook/WhatsApp** | Noyé dans le flux, pas de tri par salle/heure. | **Structuré :** Un bouton pour dire "J'ai besoin d'aide". |
| **Demander au staff** | Souvent absent (Low cost) ou occupé. | **Communautaire :** Entraide entre membres présents. |
